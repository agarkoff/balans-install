# Баланс — установка

Учёт личных финансов по выпискам банков. Работает на Windows в Docker.

Установка одной командой (PowerShell):

```powershell
irm https://raw.githubusercontent.com/agarkoff/balans-install/main/install.ps1 | iex
```

Скрипт скачивает установщик в `C:\Баланс` и запускает его: он поставит WSL и
Docker Desktop (если их нет), скачает приложение из реестра образов
`ghcr.io/agarkoff/balans`, создаст ярлыки «Баланс», «Обновить выписки» и
«Баланс — остановить». Данные остаются на вашем компьютере.

Повторный запуск той же команды — обновление: база, настройки и выписки не
затрагиваются. Обновиться можно и кнопкой «Доступна новая версия — обновить»
в самом приложении.

Другая папка установки: `$env:BALANS_DIR = "D:\Balans"` перед командой.

В этом репозитории только установщик и `compose.yml`; код приложения внутри
образа. Файлы здесь собираются автоматически при выкладке новой версии.
