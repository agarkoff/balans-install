Баланс — учёт личных финансов по выпискам банков
=================================================

Установка
---------
1. Распакуйте архив в постоянное место, например C:\Баланс (не во «Временные
   файлы»: система будет жить в этой папке).
2. Запустите «Установить.cmd» в папке Баланс.
   - Если нет подсистемы Linux (WSL) или Docker Desktop — установщик поставит
     их сам. Windows спросит разрешение (UAC) — нажмите «Да».
   - Если для этого нужна перезагрузка, установщик предложит её сразу; после
     входа в Windows установка продолжится сама — заново запускать не нужно.
     (Если по какой-то причине не продолжилась — запустите «Установить.cmd»).
   - При первом запуске Docker Desktop может попросить принять его условия
     (аккаунт Docker при этом не нужен).
   - Первая сборка занимает 5–10 минут; ход виден в окне установщика.
3. Откроется браузер с мастером настройки: ваше имя так, как банки пишут его
   в переводах себе, и дата начала учёта. Токен Т-Инвестиций и ключ ИИ
   можно задать сразу или потом в «Настройках».

Ярлыки на рабочем столе
-----------------------
- «Баланс» — запустить систему и открыть её в браузере.
- «Обновить выписки» — скачать выписки Т-Банка, Сбер Инвестиций и
  Т-Инвестиций (для Т-Инвестиций нужен токен в «Настройках»).
  Откроется отдельное окно Яндекс Браузера: при первом запуске войдите в нём
  в личные кабинеты банков и нажмите «Я вошёл — продолжить». Пароли и коды
  вводите только вы. Скачанное система разбирает сама.
- «Баланс — остановить» — остановить систему.

Обновление
----------
Приложение скачивается из реестра образов, в архиве его кода нет.
- Из самой системы: когда выходит новая версия, в шапке рядом с хешем версии
  появляется кнопка «Доступна новая версия — обновить». Нажмите её — система
  скачает обновление и перезапустится за минуту. Данные сохраняются.
- Вручную: запустите «Установить.cmd» ещё раз (он скачивает последнюю версию).
- Если реестр закрытый, установщик один раз попросит токен доступа — его
  присылает владелец. Docker запоминает вход сам.

Где что лежит
-------------
- data\raw     — скачанные выписки;
- data\backup  — резервные копии базы (раз в сутки);
- install.log  — журнал установщика: пригодится, если что-то пошло не так.
